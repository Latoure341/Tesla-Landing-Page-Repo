# Tesla Landing Page Clone

A responsive Tesla-inspired landing page built using **HTML and CSS only**.
This project replicates key sections of Tesla’s official website including navigation, sliders, offers, energy features, and footer layout.

It focuses on modern UI layout, flexbox positioning, smooth scrolling sliders, and clean visual design.

---

## Technologies Used

* **HTML5**
* **CSS3 (Flexbox & Layout Styling)**
* No JavaScript (pure CSS sliders using anchor navigation)

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/tesla-landing-page.git
   ```

2. Navigate into the folder:

   ```bash
   cd tesla-landing-page
   ```

3. Open `index.html` in your browser:

   * Double-click the file
     **or**
   * Use Live Server in VS Code
